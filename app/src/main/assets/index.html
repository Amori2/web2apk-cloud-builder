كيف تحصل على رمز GitHub للبناء السحابي المجاني؟

يُستخدم لترجمة وتوقيع ملف APK حقيقي عبر خوادم GitHub Actions الرسمية

لماذا نستخدم GitHub Actions؟ نظام أندرويد يشترط ترجمة ملفات classes.dex و AndroidManifest.xml ثنائياً وتوقيع الحزمة رقمياً عبر Gradle & Android SDK حتى يقبل الهاتف تثبيتها. هذا المحرك يقوم بذلك تلقائياً ومجاناً نيابةً عنك!
  1. سجّل الدخول إلى حسابك في GitHub.com (أو أنشئ حساباً مجانياً).
  2. انتقل إلى Settings ثم في أسفل القائمة الجانبية اختر Developer settings.
  3. اختر Personal access tokens ثم Tokens (classic) ثم اضغط Generate new token (classic).
  4. فعّل الصلاحيتين: repo و workflow فقط.
  5. انسخ الرمز الذي يبدأ بـ ghp_... والصقه في خانة البناء السحابي داخل المنصة، ثم اضغط "بدء بناء وتوليد ملف APK الآن"!
